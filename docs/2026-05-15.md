#### 📋 MVC 패턴 기반 게시판 구현
 
#### 🏗️ MVC 아키텍처
 
MVC는 애플리케이션을 세 가지 역할로 분리하여 유지보수성과 확장성을 높이는 디자인 패턴입니다.
 
| 구성 요소 | 역할 |
|-----------|------|
| **Model** | 비즈니스 로직 및 데이터 처리 (DB 연동, SQL 쿼리 실행) |
| **View** | 사용자에게 보여지는 화면 (HTML, CSS, JSP) |
| **Controller** | 요청 처리 및 Model↔View 중개 (서블릿 등) |
 
#### 흐름도
 
```
사용자 요청
    ↓
Controller  →  Model (DB 조회/처리)
    ↓              ↓
  View  ←  결과 데이터 전달
    ↓
화면 출력
```
 
#### MVC 핵심 원칙
- 각 계층은 **서로의 내부 구현을 모른 채** 인터페이스로만 통신
- View는 데이터를 직접 가져오지 않고, Controller를 통해 전달받음
- Model은 UI와 무관하게 독립적으로 동작

#### 📌 게시판 구현
 
#### 사용 기술
 
| 구분 | 기술 |
|------|------|
| 화면 구성 | HTML, CSS |
| 서버 사이드 | JSP, Java |
| 데이터베이스 연동 | SQL (JDBC) |
| 클라이언트 스크립트 | JavaScript (`history.back()`) |
 
---
 
#### 주요 기능
 
#### 1. 게시글 목록 조회
- JSP + Java를 이용해 DB에 SQL 쿼리를 실행하여 게시글 데이터를 조회
- 조회된 데이터를 HTML 테이블 형식으로 목록에 출력
#### 2. 페이지네이션 (Pagination)
- 전체 게시글을 일정 수 단위로 나누어 페이지별로 표시
- SQL의 `LIMIT` / `OFFSET` (또는 `ROWNUM`) 등을 활용해 페이지별 데이터를 쿼리
```sql
-- 페이지 나누는 쿼리문
String sql="SELECT no,subject,name,TO_CHAR(regdate,'yyyy-MM-dd'),hit "
					+"FROM jspBoard "
					+"ORDER BY no DESC "
					+"OFFSET ? ROWS FETCH NEXT 10 ROWS ONLY";

-- 총페이지 구하기
String sql="SELECT COUNT(*) FROM jspBoard";
```
 
#### 3. 글쓰기 / 수정 / 삭제
- **글쓰기**: 입력 폼(HTML/CSS) → Controller → INSERT 쿼리 실행
- **수정**: 기존 데이터 불러와 폼에 표시 → UPDATE 쿼리 실행
- **삭제**: 해당 게시글 DELETE 쿼리 실행 후 목록으로 이동
#### 4. 뒤로가기 버튼
- JavaScript의 `history.back()`을 사용해 이전 페이지로 이동
```javascript
// 목록 버튼 클릭 시 이전 페이지로 이동
function goBack() {
    history.back();
}
```

### 💡 Note
MVC구조는 실무에서도 사용되는 구조로 흐름을 파악하는게 중요하다
현재 JSP를 통해 데이터베이스를 연동하는게 중점을 두고 학습 중이다
JSP를 통해 자바 코드를 사용해서 쿼리문을 작성하고 DB의 데이터를 끌고 와서 게시판을 만들어봤는데 몇가지 주의 할 점이 있었다.
1) JSP의 <% %>, <%= %> 안에 자바 코드를 작성하고 웹 브라우저에 출력하는데 자바와 HTML을 구분하는 <% %> 사용 중에 구역을 나누는 과정에서 잦은 실수 발생했다.
2) <% %>와 <%= %>의 구분은 확실하게 : 브라우저에서 404가 나타나는 대부분의 이유가 출력용 자바 코드를 작성할때  <% %> 사이에 =을 붙이지 않아 에러가 났다
   <% %> 스크립틀릿 : 계산을 하거나 반복분을 돌리는 등 순수 자바 코드가 필요할 때 쓰임
   <%= %> 표현식 : 계산된 결과값이나 DB에서 가져온 데이터를 HTML사이에 넣을 때 사용. 쉽게 말해 자바 데이터를 브라우저에 출력할 때 사용

지금은 오타를 줄이고 흐름을 좀 더 명확하게 파악하는데 집중해야 할 거 같다.
