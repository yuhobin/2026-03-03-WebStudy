# 📅 2026-05-22 Debugging
### 🏷️ Topic
FileUpload (실전을 통한 에러잡기 Error_Day)

### 📝 What I Learned
일단 오늘은 온갖 에러를 잡는데 집중을 쏟아낸 하루였다. 값진 경험이라 생각하고 오늘 겪은 에러 해결 과정을 기록한다

### 오늘의 디버깅 기록

> 에러 페이지로 얼룩진 하루. 오타 → 경로 → 가비지 쿠키까지 세 가지 문제를 연속으로 마주했다.

---

#### 1. 오타로 인한 404 에러

| | 내용 |
|---|---|
| **에러** | 404 - 페이지를 찾을 수 없음 |
| **원인** | 단순 오타 |
| **해결** | 코드 점검 후 오타 수정 |
| **배운 점** | 오타를 줄이는 것이 가장 기본이자 급선무 |

---

#### 2. 경로 설정 문제로 인한 500 에러

| | 내용 |
|---|---|
| **에러** | 500 - `JspChange.java` 배열에 `../` 가 잘못 포함 |
| **원인** | `main.jsp`와 `databoard` 폴더가 같은 계층인데 상위 폴더 이동 기호를 사용 |
| **해결** | `../` 제거 후 정상 연결 |
| **배운 점** | 파일의 물리적 위치와 상대 경로의 관계를 정확히 파악해야 한다. 쿼리문에서 DB 데이터를 못 끌고 오는 실수와 비슷한 맥락이라고 느꼈다(사소해 보이는 작은 실수 하나가 데이터를 아예 못불러오거나 페이지를 못불러오고 에러페이지 띄우는 모습이 굉장히 비참했다) |

---

#### 3. 가비지 쿠키로 인한 500 에러 (가장 오래 걸린 문제)

| | 내용 |
|---|---|
| **에러** | 500 - `Integer.parseInt`에서 `NumberFormatException` 발생 |
| **원인** | 경로가 꼬였던 이전 단계에서 `food_null` 같은 비정상 쿠키가 브라우저에 영구 저장됨. 서버를 고쳐도 브라우저가 매번 오염된 쿠키를 전송해 에러가 반복됨 |
| **시도** | 코드 수정 → Project Clean → 톰캣 재시작 → 전부 해결 안 됨 |
| **해결** | 크롬 개발자도구(F12) → Application 탭에서 해당 쿠키 수동 삭제 |
| **추가 조치** | 같은 문제 재발 시 전체 페이지가 죽지 않도록 쿠키 로직에 `try-catch` 추가 |
| **배운 점** | 서버와 코드가 정상이어도 **브라우저에 오염된 쿠키가 남아있으면 에러가 반복**될 수 있다. 서버 문제가 아닐 경우 클라이언트(브라우저) 쪽도 의심해볼 것. StackTrace를 참고하면 코드를 수정하고 서버를 재시작해도 안되자 마지막으로 시도한 방법이었는데 다행히 적중했다. 고난을 겪고 원인을 파악하니 정말 값진 경험이었다 |

---

#### 4. 중괄호 스코프 오류로 인한 컴파일 에러

| | 내용 |
|---|---|
| **에러** | `UploadServlet.java` 컴파일 에러 |
| **원인** | `doPost` 메서드의 중괄호가 31번째 줄에서 바로 닫혀 하위 코드들이 메서드 바깥으로 노출. 추가로 `upliadDir`, `DateBoardVO` 등 스펠링 오타 |
| **해결** | 중괄호 스코프를 메서드 끝으로 이동 + 오타 수정 |
| **배운 점** | 중괄호 누락은 찾기 어려운 편이라 IDE의 코드 접기 기능을 활용해 스코프를 확인하는 습관이 필요하다 |

---

#### 오늘의 디버깅 핵심 정리

```
에러가 반복될 때 체크 순서

1. 코드 오타 확인
2. 파일 경로 / 상대 경로 확인
3. 서버 Clean + 재시작
4. 그래도 안 되면 → 브라우저 쿠키 삭제 (클라이언트 쪽 의심)
5. 스택 트레이스(Stack Trace)로 예외 발생 지점 추적
```

### 💡 Note

에러페이지로 얼룩진 하루다
처음에 사소한 오타로 404에러가 뜨더니
나중에 경로 설정 문제로 500에러가 뜨고
마지막엔 쿠키가 오염되서 시스템이 망가져 500에러 페이지가 뜨더니 쿠기 삭제를 하고 나서야 해결이 됐다(쓰레기 데이터가 남아서 시스템이 꼬인거 같다)
일단 당연하지만 오타를 줄이는게 가장 급선무이고
경로 설정 문제에선 연결된 페이지의 경로를 줄때 정확한 경로를 신중하게 줘야될거 같다(쿼리문 실수로 DB의 데이터를 못끌고 오는것과 비슷한 느낌이다)
마지막에 나왔던 쿠키관련오류는 처음 겪어 봤는데 처음엔 코드를 잘못 짠 줄알고 Stack Trace 참고해 이것 저것 다해봐도 도저히 해결이 되지 않았다. 
그래서 무언가 시스템 내부에서 꼬인거 같아 톰캣을 restart하고 Clean을 해봐도  해결이 되지 않아 에러난 데이터가 저장되어 가비지 쿠키가 남아 시스템이 망가진건가 하고 
브라우저에서 쿠키를 삭제해보니 문제가 해결됐다
