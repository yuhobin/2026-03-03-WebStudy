### EL (Expression Language)

- JSP에서 자바 코드를 최소화하고 값을 출력하기 위한 표현식
- J2EE에 독립적으로 포함된 언어 (JSTL 라이브러리 불필요)
- `<%= %>` 대신 `${}` 사용
- **JSP에서 `<% %>`, `<%! %>`, `<%= %>`는 사용하지 않는다**

#### 주의
- `${}` 안에는 일반 변수 출력 불가
- `request.setAttribute()` 또는 `session.setAttribute()`로 전달된 값만 출력 가능

```java
// Java
request.setAttribute("name", "홍길동");
```
```jsp
// JSP
${name}  <!-- 출력 가능 -->
```

### 연산자

#### 산술 연산자
| 표현 | 결과 | 비고 |
|------|------|------|
| `${"10" + 10}` | 20 | 문자열 자동 숫자 변환 |
| `${10 + null}` | 10 | null은 0으로 취급 |
| `${"10" += 10}` | 1010 | `+=`는 문자열 결합 |
| `${5 / 2}` 또는 `${5 div 2}` | 2.5 | 정수/정수 = 실수 |
| `${5 % 2}` 또는 `${5 mod 2}` | 1 | 나머지 |

#### 비교 연산자 (결과: true/false)
| 기호 | 문자 표현 |
|------|-----------|
| `==` | `eq` |
| `!=` | `ne` |
| `<` | `lt` |
| `>` | `gt` |
| `<=` | `le` |
| `>=` | `ge` |

#### 논리 연산자
`&&` → `and` / `||` → `or` / `!` → `not`

#### 삼항 연산자
```jsp
${조건 ? 값1 : 값2}
```

#### Empty 연산자 ★
```jsp
${empty 변수}  <!-- 변수가 "", null이면 true -->
```
댓글 존재 여부, 장바구니 확인 등에 활용

### 내장 객체

| 내장 객체 | 대응하는 Java 코드 | 사용 범위 |
|-----------|-------------------|-----------|
| `requestScope` | `request.getAttribute()` | MVC 구조 |
| `sessionScope` | `session.getAttribute()` | MVC 구조 |
| `pageContext` | 경로 설정 (`<link>`, `<a href>` 등) | MVC 구조 |
| `param` | `request.getParameter()` | JSP 단독 |
| `paramValues` | `request.getParameterValues()` | JSP 단독 |
| `applicationScope` | `application.getAttribute()` | JSP 단독 |

### JSTL (Java Standard Tag Library)

- JSP에서 자바 제어문을 태그 형태로 작성하는 표준 라이브러리
- EL과 함께 사용하며 SpringFramework, Spring-Boot 환경에서도 활용

---

#### *core  (`prefix="c"`, `uri="jakarta.tags.core"`)

#### 변수 선언
```jsp
<c:set var="name" value="홍길동"/>
<!-- request.setAttribute("name", "홍길동") 과 동일 -->
```

#### 반복문
```jsp
<!-- for (int i=1; i<=10; i++) -->
<c:forEach var="i" begin="1" end="10" step="1">
    ${i}
</c:forEach>

<!-- for (BoardVO vo : list) -->
<c:forEach var="vo" items="${list}">
    ${vo.name}
</c:forEach>
```

#### 조건문
```jsp
<!-- if -->
<c:if test="${i > 10}">출력값</c:if>
<c:if test="${name == 'aaa'}">출력값</c:if>

<!-- if~else / 다중 조건 -->
<c:choose>
    <c:when test="${조건}">출력값</c:when>   <!-- if -->
    <c:when test="${조건}">출력값</c:when>   <!-- else if -->
    <c:otherwise>출력값</c:otherwise>        <!-- else -->
</c:choose>
```

#### 화면 이동
```jsp
<c:redirect uri="list.jsp"/>
<!-- response.sendRedirect("list.jsp") 과 동일 -->
```

---

#### format (`prefix="fmt"`, `uri="jakarta.tags.format"`)

```jsp
<!-- 날짜 포맷 (SimpleDateFormat / TO_CHAR) -->
<fmt:formatDate value="${vo.regdate}" pattern="yyyy-MM-dd"/>

<!-- 숫자 포맷 (DecimalFormat / TO_CHAR) -->
<fmt:formatNumber value="1234567" type="currency"/>
<!-- 출력: 1,234,567 -->
```

---

#### function (`prefix="fn"`, `uri="jakarta.tags.functions"`)

Java `String` 클래스 메서드를 EL에서 사용 가능

```jsp
${fn:length(list)}
${fn:substring(str, 0, 5)}
${fn:trim(str)}
```

### 한눈에 비교

| | EL | JSTL |
|---|---|---|
| 역할 | 값 출력 | 제어문 (반복, 조건, 이동) |
| 라이브러리 필요 | ❌ | ✅ |
| 대체 문법 | `<%= %>` | `<% for() %>`, `<% if() %>` |
| 사용 환경 | JSP, Spring, SpringBoot | JSP, Spring, SpringBoot |
