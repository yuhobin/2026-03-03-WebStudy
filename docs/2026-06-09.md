## 1. DOM (Document Object Model)

### 1) DOM이란?

브라우저가 HTML 파일을 읽으면 각 태그를 **객체(Object)로 변환**해 메모리에 트리 형태로 저장한다.  
이 구조 전체를 **DOM(문서 객체 모델)** 이라 하며, JavaScript는 DOM을 통해 HTML 태그를 제어한다.

```
HTML 파일  →  (브라우저 파싱)  →  DOM 트리 (메모리)  →  JavaScript로 조작
```

> **Java와 비교**  
> HTML 태그는 Java의 클래스, 태그의 속성은 멤버 변수와 같은 개념이다.
> ```java
> // <a href="https://google.com" target="_blank"> 를 Java로 표현하면:
> class HTMLAnchorElement {
>     String href   = "https://google.com";
>     String target = "_blank";
> }
> ```

**역할 구분**

| 기술 | 역할 |
|---|---|
| HTML | 화면 구조 설계 (뼈대) |
| CSS | 스타일·디자인 (꾸미기) |
| JavaScript + DOM | 동적 기능 부여 (살아있게 만들기) |

---

### 2) DOM 트리 구조

HTML이 메모리에 올라갈 때 아래와 같은 트리 형태로 저장된다.

```
          html
           |
     ------+------
     |            |
    head         body
                  |
          --------+--------
          |        |       |
         div      div    span
```

- 최상위 노드는 `document` 객체이며, JavaScript에서 DOM에 접근하는 진입점이다.
- 모든 태그는 **노드(Node)** 이고, 부모·자식·형제 관계로 연결된다.

---

### 3) 문서 객체 선택

태그를 조작하려면 먼저 해당 태그를 **선택(가져오기)** 해야 한다.

#### 1. `getElementById` — id 속성으로 선택 (가장 기본)

```html
<button id="btn">클릭</button>
```
```javascript
let btn = document.getElementById("btn");
```

- 결과: **단일 요소** 1개 반환
- id는 페이지 내에서 고유해야 하므로 항상 하나만 반환

---

#### 2. `getElementsByClassName` — class 속성으로 선택

```html
<button class="btns">버튼1</button>
<button class="btns">버튼2</button>
<button class="btns">버튼3</button>
```
```javascript
let btns = document.getElementsByClassName("btns");

// 여러 개이므로 for문으로 순회
for (let i = 0; i < btns.length; i++) {
    console.log(btns[i]);
}
```

- 결과: **HTMLCollection** (배열 유사 객체) 반환 → for문 필요

---

#### 3. `querySelector` / `querySelectorAll` — CSS 선택자로 선택 ★ 가장 권장

```javascript
// querySelector : 조건에 맞는 첫 번째 요소 1개만 반환
document.querySelector("#id명")               // id 선택
document.querySelector(".class명")            // class 선택
document.querySelector("태그명")              // 태그 선택
document.querySelector("div > p")             // 자손 선택 (직계)
document.querySelector("div p")               // 후손 선택
document.querySelector("input[type='text']")  // 속성 선택자
document.querySelector("input[name*='user']") // 속성값 포함 (*=)
document.querySelector("input[name$='Id']")   // 속성값 끝 ($=)
document.querySelector("input[name^='user']") // 속성값 시작 (^=)
document.querySelector("li:nth-child(2)")     // 구조 선택자

// querySelectorAll : 조건에 맞는 모든 요소 반환 (NodeList)
let items = document.querySelectorAll(".item");
items.forEach(item => console.log(item));
```

> **왜 querySelector를 권장하는가?**  
> CSS 선택자 문법을 그대로 사용할 수 있어 id·class·태그·속성 조건을 자유롭게 조합할 수 있다.  
> 이후 배우는 jQuery(`$()`)도 동일한 선택자 문법을 사용하므로 익혀두면 바로 연결된다.

---

#### 4. `getElementsByTagName` — 태그명으로 선택

```javascript
let rows = document.getElementsByTagName("tr");
```

- `<th>`, `<li>` 같이 동일 태그 여러 개를 한 번에 읽어올 때 사용

---

#### 선택 메서드 비교 정리

| 메서드 | 선택 기준 | 반환 결과 |
|---|---|---|
| `getElementById` | id 속성 | 요소 1개 |
| `getElementsByClassName` | class 속성 | HTMLCollection (복수) |
| `getElementsByTagName` | 태그명 | HTMLCollection (복수) |
| `getElementsByName` | name 속성 | NodeList (복수) |
| `querySelector` | CSS 선택자 | 요소 1개 (첫 번째) |
| `querySelectorAll` | CSS 선택자 | NodeList (복수) |

---

### 4) 문서 객체 조작

태그를 선택한 후에는 **글자 / 스타일 / 속성** 세 가지를 조작할 수 있다.

#### 1. 글자(텍스트) 조작

```javascript
let el = document.querySelector("#title");

el.textContent = "새 제목";          // 순수 텍스트만 변경 (HTML 태그 무시)
el.innerHTML   = "<b>굵은 제목</b>"; // HTML 태그 포함해서 변경
```

| 속성 | 설명 | 사용 시점 |
|---|---|---|
| `textContent` | 텍스트만 변경, 태그 무시 | 단순 문자 출력 |
| `innerHTML` | HTML 태그 포함 변경 | 태그 구조 동적 생성 |

---

#### 2. 스타일 조작

```javascript
let box = document.querySelector(".box");

box.style.color      = "red";
box.style.display    = "none";      // 숨기기
box.style.display    = "block";     // 보이기
box.style.marginTop  = "10px";      // CSS의 margin-top → JS에서는 camelCase
box.style.fontSize   = "20px";      // CSS의 font-size → fontSize
```

> **CSS 속성명 → JavaScript camelCase 변환 규칙**  
> CSS에서 하이픈(-)으로 연결된 속성명은 JavaScript에서 camelCase로 작성한다.  
> `margin-top` → `marginTop` / `background-color` → `backgroundColor`

클래스를 통한 스타일 조작 (권장):

```javascript
el.classList.add("active");      // 클래스 추가
el.classList.remove("active");   // 클래스 제거
el.classList.toggle("active");   // 있으면 제거, 없으면 추가
el.classList.contains("active"); // 클래스 포함 여부 확인 (true/false)
```

---

#### 3. 속성 조작

```javascript
let img = document.querySelector("img");
let a   = document.querySelector("a");

// 직접 접근 (표준 속성)
img.src  = "new-image.jpg";
a.href   = "https://google.com";

// getAttribute / setAttribute (모든 속성 범용)
img.getAttribute("src");                  // 속성값 읽기
img.setAttribute("src", "new-image.jpg"); // 속성값 변경
img.setAttribute("alt", "이미지 설명");   // 없는 속성도 추가 가능
img.removeAttribute("alt");               // 속성 제거
```

## 2. 이벤트 처리 (Event Handling)

### 1) 이벤트란?

사용자가 브라우저 안에서 행위(클릭, 키 입력, 마우스 이동 등)를 했을 때 발생하는 **신호**다.  
JavaScript는 이 신호를 감지해 미리 정의한 함수를 실행한다.

```
사용자 행위 → 이벤트 발생 → 이벤트 핸들러(함수) 실행 → DOM 조작 → 화면 변경
```

---

### 2) 주요 이벤트 종류

| 이벤트 | 발생 시점 | 주로 사용하는 태그 |
|---|---|---|
| `click` | 마우스 클릭 | button, a, img |
| `mouseover` | 마우스 올렸을 때 | img, div |
| `mouseout` | 마우스 벗어났을 때 | img, div |
| `keydown` | 키보드 키를 눌렀을 때 | input, textarea |
| `keyup` | 키보드 키를 뗐을 때 | input, textarea |
| `change` | 값이 변경됐을 때 | select, input |
| `submit` | 폼 제출 시 | form |
| `input` | 입력값이 바뀔 때마다 | input, textarea |

---

### 3) 이벤트 처리 방식 3가지

#### 방식 1. 인라인 이벤트 모델

HTML 태그 안에 직접 이벤트 속성을 작성하는 방식.

```html
<button onclick="handleClick()">클릭</button>

<script>
    function handleClick() {
        alert("클릭됨!");
    }
</script>
```

- HTML과 JavaScript 코드가 섞여 유지보수가 어려움
- Vue(`v-on:click`, `@click`), React(`onClick`)의 기반 개념이 이 방식에서 출발

---

#### 방식 2. 고전 이벤트 모델

JavaScript에서 태그를 선택한 뒤 이벤트 속성에 함수를 직접 대입하는 방식.

```javascript
let btn = document.getElementById("btn");

btn.onclick = function() {
    alert("클릭됨!");
};
```

- HTML과 JavaScript를 분리할 수 있어 인라인보다 구조가 깔끔함
- 단점: 같은 이벤트에 함수를 하나만 등록할 수 있음 (덮어쓰기 발생)

---

#### 방식 3. 이벤트 리스너 *** 현재 표준 권장 방식

`addEventListener`를 사용해 이벤트를 등록하는 방식.

```javascript
let btn = document.getElementById("btn");

btn.addEventListener("click", function() {
    alert("클릭됨!");
});
```

```javascript
// 화살표 함수로도 작성 가능
btn.addEventListener("click", () => {
    alert("클릭됨!");
});
```

- 같은 요소에 **여러 이벤트 핸들러를 중복 등록** 가능 (고전 방식과의 차이)
- jQuery에서는 `.on('click', function(){})` 으로 사용 (jQuery 4버전 권장)
- `removeEventListener`로 이벤트 제거도 가능

---

#### 이벤트 처리 방식 비교

| 방식 | 코드 위치 | 중복 등록 | 현재 사용 |
|---|---|---|---|
| 인라인 이벤트 | HTML 태그 속성 | 불가 | Vue/React 학습 시 개념 이해용 |
| 고전 이벤트 | JS 파일 / script 태그 | 불가 (덮어쓰기) | jQuery 학습 시 참고 |
| 이벤트 리스너 | JS 파일 / script 태그 | 가능 | ✅ 표준, 권장 |

---



#### 이후 학습 흐름

```
DOM 조작 + 이벤트
    ↓
Ajax (비동기 — 서버 데이터를 페이지 새로고침 없이 가져오기)
    ↓
jQuery (DOM + 이벤트 + Ajax를 간결하게 작성하는 라이브러리)
    ↓
Vue.js (컴포넌트 방식 — DOM 조작을 프레임워크가 자동 처리)
```

### 배운점

- 이벤트 처리를 통해 동적인 효과를 부여하니 페이지가 살아있는 느낌이 들었고, JavaScript가 단순한 스크립트가 아니라 사용자 경험을 만드는 핵심 도구라는 것을 체감함
- Java 기반 백엔드(MVC, MyBatis 흐름, 데이터 연동)는 어느정도 파악하고 있고  기본 틀을 작성 및 수정할 수 있는 수준이나, JavaScript는 제어문·연산자 등 기본 문법은 Java와 유사함에도 불구하고 전체적인 코드 구조가 낯설어 한눈에 파악이 아직 어려움
- 특히 이벤트 처리나 로직을 담당하는 코드를 직접 작성할 때 구조 파악이 어려워 깔끔한 코드를 짜는 데 어려움이 있음 → 실습을 통해 코드를 눈에 익히고 전체 구조 파악에 집중 중
