## 1. Vue.js를 사용하는 목적

1\) **상태 관리(State Management)**
- 화면에 표시되는 **데이터(변수)를 중앙에서 관리**하는 것이 핵심 목적
- 데이터가 변경되면 View(화면)가 **자동으로 갱신**됨
- React의 `state`, Angular의 `binding`과 동일한 개념

2\) **컴포넌트 기반 개발**
- UI를 독립적인 컴포넌트 단위로 분리해 재사용성과 유지보수성을 높임
- 부분적인 화면 처리 가능 (상세보기, 결제 정보, 예약 정보 등)

## 2. Vue.js의 특징

1\) **장점**

## 3. MVVM 구조

Vue.js는 **MVVM(Model-View-ViewModel)** 패턴을 따름

```
View (HTML) ←──────────────────────────────────────────┐
    │                                                  │
    │  사용자 입력                                     │ 화면 갱신
    ▼                                                  │
ViewModel (Vue Instance) ──── 데이터 변경 감지 ────────┘
    │
    │ 데이터 바인딩
    ▼
Model (data() 내부 변수)
```

| 구성 요소 | 역할 |
|----------|------|
| **Model** | 데이터를 저장하는 공간 (`data()` 내부의 변수) |
| **View** | 사용자에게 보이는 HTML 화면 |
| **ViewModel** | 데이터를 감지하고 View에 자동 반영하는 Vue 인스턴스 |

- **양방향 통신** : View에서 입력한 값이 Model에 즉시 반영되고, Model이 바뀌면 View도 자동 갱신
- `this.변수명` 으로 `data()`에 선언한 멤버변수에 접근

## 4. Vue 인스턴스 구조

```javascript
const app = Vue.createApp({

    // 1) 데이터 선언 : HTML에서 사용할 변수 정의
    data() {
        return {
            message: 'Hello Vue!',
            count: 0
        }
    },

    // 2) 생명주기 함수 (아래 섹션 참고)
    mounted() {
        // DOM 로드 완료 후 실행 (jQuery의 $(function(){}) 와 동일)
    },

    // 3) 이벤트 처리 : 사용자 정의 함수
    methods: {
        increment() {
            this.count++;
        }
    },

    // 4) 자식 컴포넌트 등록
    components: {
        // 다른 화면(컴포넌트)을 등록해서 관리
    },

    // 5) 계산된 속성 : 데이터를 가공해서 반환 (ex. 천 단위 콤마)
    computed: {
        formattedCount() {
            return this.count.toLocaleString(); // 예: 10000 → 10,000
        }
    },

    // 6) 감시자 : 특정 데이터 변화를 감지해서 처리
    watch: {
        count(newVal, oldVal) {
            console.log(`${oldVal} → ${newVal}`);
        }
    }

});

app.mount('#app');
```

## 5. 생명주기(Lifecycle)

Vue 인스턴스가 생성되고 소멸되기까지의 단계별 훅(hook) 함수

```
[생성]
beforeCreate()   : 인스턴스 초기화 직전, data / methods 접근 불가
created()        : data / methods 사용 가능, DOM은 아직 미연결
beforeMount()    : 템플릿 컴파일 완료, DOM 연결 직전
mounted()        : DOM 연결 완료 → jQuery의 $(function(){}) 와 동일한 시점

[갱신]
beforeUpdate()   : 데이터 변경 감지, DOM 갱신 직전
updated()        : DOM 갱신 완료 후

[소멸]
beforeDestroy()  : 인스턴스 소멸 직전 (정리 작업)
destroyed()      : 인스턴스 소멸 완료
```

>  **실무 포인트** : 초기 데이터 로딩(Ajax 호출 등)은 주로 `mounted()` 또는 `created()`에서 처리

## 6. 가상 DOM(Virtual DOM)

1\) **개념**
- Vue는 실제 브라우저 DOM을 직접 수정하지 않고, 메모리 상의 **가상 DOM**에 먼저 변경 사항을 반영
- 이후 실제 DOM과 **diff(차이 비교)** 알고리즘으로 변경된 부분만 효율적으로 업데이트

2\) **동작 원리**

```
사용자 입력
    │
    ▼
Vue 가상 DOM (메모리) ──── diff 비교 ────► 변경된 부분만 실제 DOM에 반영
                                                    │
                                                    ▼
                                            브라우저 화면 갱신
```

3\) **장점**
- 불필요한 전체 리렌더링을 방지해 **성능 최적화**
- 사용자 입력 데이터와 저장 데이터가 **동시에 처리** 가능

## 7. 디렉티브(Directive)

HTML 태그 내부에서 `v-` 접두어로 사용하는 Vue 전용 명령어

1\) **조건부 렌더링**

```html
<!-- 단순 조건 -->
<p v-if="isLogin">환영합니다!</p>

<!-- if / else -->
<p v-if="score >= 60">합격</p>
<p v-else>불합격</p>

<!-- if / else if / else -->
<p v-if="grade === 'A'">우수</p>
<p v-else-if="grade === 'B'">보통</p>
<p v-else>미흡</p>
```

> `v-if` : 조건이 false면 DOM에서 **완전히 제거**  
> `v-show` : 조건이 false면 `display:none` 처리 (DOM은 유지)

2\) **반복 렌더링**

```html
<!-- 배열 반복 -->
<li v-for="item in items" :key="item.id">{{ item.name }}</li>

<!-- 숫자 반복 (1~10) -->
<li v-for="n in 10">{{ n }}</li>
```

>  **주의** : `v-for`와 `v-if`는 **같은 태그에 동시 사용 불가**  
> 해결법 : `v-for` 바깥에 `<template v-if="">` 또는 `computed`로 필터링 후 사용

3\) **데이터 바인딩**

```html
<!-- v-bind : 속성에 데이터 바인딩 (단방향) -->
<img v-bind:src="imageUrl">
<img :src="imageUrl">          <!-- 축약형 -->

<!-- v-model : 입력 폼과 데이터 양방향 바인딩 -->
<input v-model="username" type="text">
<p>입력값: {{ username }}</p>
```

4\) **이벤트 처리**

```html
<!-- v-on:이벤트명 -->
<button v-on:click="handleClick">클릭</button>

<!-- 축약형 @ -->
<button @click="handleClick">클릭</button>
<input @keyup.enter="submitForm">
```

5\) **디렉티브 요약**

| 디렉티브 | 역할 |
|---------|------|
| `v-if` / `v-else` / `v-else-if` | 조건부 렌더링 (DOM 제거/추가) |
| `v-show` | 조건부 표시 (display 속성 제어) |
| `v-for` | 반복 렌더링 |
| `v-bind` (`:`) | 속성에 데이터 바인딩 (단방향) |
| `v-model` | 폼 입력과 데이터 양방향 바인딩 |
| `v-on` (`@`) | 이벤트 리스너 등록 |

## 8. Vue 생태계

1\) **상태 관리 라이브러리**
- **Vuex** : Vue 2/3 공식 상태 관리 라이브러리
- **Pinia** : Vue 3 권장 상태 관리 라이브러리 (Vuex의 후속, 더 단순한 구조)

2\) **관련 기술 스택 비교**

| 구분 | Vue 생태계 | 유사 기술 |
|------|-----------|---------|
| UI 프레임워크 | Vue.js | React, Angular |
| 상태 관리 | Pinia (구 Vuex) | Redux (React) |
| 표준화 프레임워크 | Nuxt.js | Next.js (React 기반) |
| 타입 안정성 | TypeScript | TypeScript |

3\) **MVC vs Spring 비교 관점**
- 프론트엔드 Vue의 **컴포넌트** 개념 ↔ 백엔드 Spring의 **MVC 구조**
- 데이터 타입이 맞지 않는 경우 → **TypeScript** 도입으로 해결
